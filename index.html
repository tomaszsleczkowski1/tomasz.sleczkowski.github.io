ESP32 3.1 Audio System

Własny system audio 3.1 oparty o platformę ESP32. Projekt zakłada obsługę Spotify Connect oraz Bluetooth Audio, cyfrowe przetwarzanie sygnału audio oraz współpracę z wielokanałowym wzmacniaczem.

🟡 Project in progress ESP32 Audio 3.1 Hardware + Firmware
Project progress 15%

Project Overview

Cel projektu

Zaprojektowanie własnego urządzenia audio 3.1 integrującego funkcje sieciowe, Bluetooth, cyfrowe przetwarzanie audio oraz końcówkę mocy.

Źródła audio

Głównymi źródłami sygnału mają być Spotify Connect oraz Bluetooth Audio.

System wyjściowy

System 3.1 składający się z kanałów Left, Right oraz Subwoofer.
